삐삐 개인정보 처리방침

시행일: 2026-11-17 · 앱: 삐삐(kr.ghbcode.beepbeep) · 개발자: ghbcompany(정희석) · 문의: Play 스토어 삐삐 앱 페이지의 «개발자 연락처» 이메일

삐삐는 가족이 서로를 호출하는 앱입니다. 호출은 무음·진동 상태에서도 소리가 납니다. 서비스에 꼭 필요한 정보만 모읍니다.

모으는 정보

정보왜 필요한가어디에 있나
표시 이름(내가 정한 이름)호출을 받는 사람에게 «누가 불렀는지» 보여 주고 그룹 구성원 목록에 표시서버(Google Firestore)
익명 계정 ID(Firebase 익명 로그인이 만든 임의 ID)내 계정과 그룹을 구분Firebase Authentication, 서버

접속 IP 주소, 기기 정보(Firebase 가 자동 수집)익명 계정을 만들고 로그인할 때 보안과 남용 방지Google Firebase
Firebase 설치 ID, 앱 버전알림 전달(FCM)과 Firebase 서비스 운영Google Firebase

위 마지막 두 줄은 삐삐 서버가 아니라 Firebase SDK 가 자동으로 수집하는 정보이며, Google 의 정책에 따라 처리됩니다(Firebase 데이터 공개 안내).

모으지 않는 정보: 전화번호, 이메일, 연락처, 위치, 사진, 마이크·카메라 입력, 광고 식별자. 광고를 보여 주지 않고, 분석(통계) 도구를 쓰지 않습니다.

앱은 호출 소리를 내고 화면을 켜기 위해 알림, 방해금지 접근, 전체 화면 알림, 포그라운드 서비스 권한을 요청합니다. 이 권한으로 얻은 정보는 서버로 보내지 않습니다.

기기에 저장하는 정보

앱이 기기에 남기는 값은 세 곳입니다.

  • 앱 설정 파일: 마지막으로 쓴 내 이름, 내가 만든 그룹별 초대 링크, 초대 링크로 들어오는 중일 때의 초대 토큰(임시), 계정 삭제 진행 상태와 실패 횟수. 이름은 그룹 가입 때, 초대 토큰은 가입을 확인할 때 서버로 보내지만 이 파일 자체는 서버로 올라가지 않습니다. «계정 삭제»가 끝나면(계정 삭제를 몇 번 다시 시도해도 안 될 때 로그아웃하는 경우 포함) 이 파일의 값이 모두 지워집니다.
  • 업데이트 안내 설정 파일: «나중에»를 누른 버전과 시각. 서버로 보내지 않습니다.
  • 알람 볼륨 파일: 호출이 울리는 동안만 원래 알람 볼륨 숫자 하나를 두고, 호출이 끝나 볼륨을 되돌리면 지웁니다. 서버로 보내지 않으며 «계정 삭제»와 별개로 관리됩니다.

위치·연락처·기기 고유 식별자는 저장하지 않습니다.

어떻게 쓰나

위 정보는 호출을 보내고 받고, 가족 그룹을 운영하는 데만 씁니다. 판매하거나 광고에 쓰지 않고, 서비스를 돌리는 Google(Firebase)·Cloudflare 외에는 제3자에게 넘기지 않습니다. 전송 구간은 HTTPS 로 암호화합니다.

앱 업데이트 안내

새 버전이 있으면 앱 첫 화면에 알려 줍니다. 이 확인은 Google Play 가 맡습니다(Play 앱 내 업데이트). 확인할 때 Google 은 기기 정보, 앱 버전, 설치된 모듈 목록을 받으며, 개발자는 이 값을 받지 않습니다. Play 로 설치하지 않았거나 확인에 실패하면 안내를 띄우지 않습니다. 업데이트 안내는 호출이 울리는 중에는 띄우지 않습니다.

앱 무결성 확인(Firebase App Check)

삐삐 서버에 요청을 보낼 때 앱은 «정품 삐삐 앱에서 온 요청인지» 확인하는 토큰(Firebase App Check)을 함께 보냅니다. 정식 배포본에서는 Google Play Integrity 가 이 토큰을 발급하며, 이 과정에서 Google 은 앱과 기기의 무결성 확인에 필요한 정보를 처리합니다(Firebase App Check 안내). 서버는 설정이 켜진 경우에만 이 토큰을 검증하며, 토큰을 발급받지 못하면 앱은 토큰 없이 요청합니다. 토큰은 가짜 앱이나 자동화된 도구가 서버를 남용하는 것을 막는 데만 쓰고, 개발자가 이 정보를 따로 저장하거나 다른 곳에 쓰지 않습니다.

서비스 제공사

  • Google Firebase(Authentication, Firestore, Cloud Messaging, App Check): 계정·데이터 저장, 알림 전달, 앱 무결성 확인. Firebase 개인정보 안내
  • Cloudflare(Workers): 앱과 서버 사이의 요청을 처리. 접속 IP 같은 요청 정보가 Cloudflare 정책에 따라 일시 처리됩니다. 앱은 이를 저장하지 않습니다.

보관과 삭제

  • 앱의 «계정 삭제»를 누르면 서버가 표시 이름, 그룹 가입 정보, 내가 보내거나 받은 호출 기록, 알림 등록 토큰을 지웁니다. 삭제 요청이 접수되면 앱의 그룹 구성원 목록에서 제외되고 새 호출 요청은 차단됩니다. 남은 서버 데이터는 정기 정리 작업이 이어서 삭제하며, 처리량이나 일시적 오류에 따라 완료까지 시간이 걸릴 수 있습니다. 앱은 접수 응답을 받은 뒤 익명 계정(Firebase Authentication) 삭제를 진행하는데, 네트워크 문제로 실패하면 몇 번 다시 시도하고 그래도 안 되면 로그아웃만 하고 계정이 남을 수 있습니다. 서버 정리가 끝나지 않았다면 앱을 다시 열 때 이어서 진행합니다. 호출 알림은 Google FCM 이 최선 노력으로 전달하므로, 이미 보낸 알림이 기기에 늦게 도착하거나 FCM 쪽에 잠시 남아 있을 수 있고 우리가 되돌릴 수 없습니다.
  • 앱을 지운 뒤에도 서버 데이터를 지우고 싶은 경우의 안내는 계정·데이터 삭제 안내에 있습니다(앱을 잃은 경우 12개월 비활동 자동 삭제가 적용됩니다).
  • 12개월 동안 앱을 실행하지 않고 호출도 받지 않은 계정은 서버가 위와 같은 데이터를 자동으로 지웁니다. 사용 기록(마지막 사용 시각)을 이 판단에만 씁니다.
  • 삭제 뒤에는 계정 ID 와 삭제 시각만 남기는 «삭제 표식»이 있습니다. 같은 계정으로 데이터가 다시 생기지 않게 하려는 것이며 90일 뒤 지웁니다.
  • 그룹 초대 링크는 7일 뒤 만료됩니다.
