삐삐 계정·데이터 삭제 안내

앱: 삐삐(kr.ghbcode.beepbeep) · 개발자: ghbcompany(정희석)

삐삐는 가입 절차 없이 익명으로 시작하며, 이름을 정해 가족 그룹에 들어갑니다. 이 쪽에서 계정과 데이터를 지우는 방법을 안내합니다.

앱에서 지우기 (가장 빠릅니다)

  1. 삐삐를 열고 가족 그룹 화면으로 갑니다.
  2. «계정 삭제»를 누르고 확인합니다.

서버에서 지우는 것: 표시 이름, 가족 그룹 가입 정보, 내가 보내거나 받은 호출 기록, 알림 등록 정보(FCM 토큰). 삭제 요청이 접수되면 앱의 그룹 구성원 목록에서 제외되고 새 호출 요청은 차단됩니다. 남은 서버 데이터는 정기 정리 작업이 이어서 삭제하며, 처리량이나 일시적 오류에 따라 완료까지 시간이 걸릴 수 있습니다. 앱은 접수 응답을 받은 뒤 익명 로그인 계정 삭제를 진행합니다. 네트워크 문제로 계정 삭제가 실패하면 몇 번 다시 시도하고, 그래도 안 되면 로그아웃만 되고 익명 계정이 남을 수 있습니다. 서버 정리가 끝나지 않았다면 앱을 다시 열 때 이어서 진행합니다. 호출 알림은 Google FCM 이 최선 노력으로 전달하므로, 이미 보낸 알림이 기기에 늦게 도착하거나 FCM 쪽에 잠시 남아 있을 수 있고 우리가 되돌릴 수 없습니다.

방장이 삭제하면 그룹 규칙(다른 구성원에게 방장 이양, 구성원이 없으면 그룹 삭제)을 따릅니다.

앱을 지웠거나 기기를 잃어버렸다면

앱만 지워서는 서버 데이터가 지워지지 않습니다. 앱을 다시 설치하면 새 계정이 만들어져 이전 계정을 이어받을 수 없고, 이전 계정의 데이터를 본인이 직접 지울 수도 없습니다. 대신 12개월 동안 앱을 실행하지 않고 호출도 받지 않은 계정은 서버가 자동으로 삭제합니다(앱 실행·알림 등록 갱신, 또는 상대가 보낸 호출이 전달된 것을 사용으로 봅니다). 삭제가 끝나면 아래 «삭제 표식» 말고는 남지 않습니다. 이메일 요청은 본인 확인 방법이 없어 별도로 처리하지 않습니다.

기기를 아직 가지고 있다면 앱을 지우기 전에 위 «계정 삭제»를 먼저 눌러 주세요.

같은 가족 그룹이 있다면 그룹 방장에게 «그룹에서 빼 달라»고 요청할 수 있습니다. 이는 그룹에서 빠지는 것이지 계정 삭제가 아닙니다.

문의: Play 스토어 삐삐 앱 페이지의 «개발자 연락처» 이메일. 이메일로 요청해도 계정 ID 만으로는 본인임을 확인할 수 없어, 확인 방법이 정해지기 전에는 처리 기한을 약속하지 않습니다.

남는 정보

  • 삭제 표식(계정 ID 와 삭제 시각만). 삭제 뒤 같은 계정으로 데이터가 다시 생기지 않게 하려고 보관하며 90일 뒤 지웁니다.
  • 서비스 제공사(Google Firebase, Cloudflare)가 자체 정책에 따라 보관하는 접속 기록.

자세한 수집 항목은 개인정보 처리방침을 보세요.
